# 👟 Converse Chuck Taylor All Star Low Top

A simple product landing page built using HTML and CSS. This project showcases a Converse Chuck Taylor All Star Low Top shoe with a clean and minimal UI design.

---

## 🌐 Live Demo
👉 https://converse-landing-page.netlify.app/

---

## 📌 About the Project
This project is a beginner-level frontend web page focused on product presentation. It displays a single product with a simple layout and a call-to-action button that includes a hover effect.

---

## ✨ Features
- Product showcase layout
- Clean and minimal design
- Call-to-action button with hover effect
- Basic UI styling using CSS

---

## 🛠️ Technologies Used
- HTML
- CSS

---

## 🎯 Purpose
This project was created to practice basic HTML and CSS skills, especially layout structuring and styling a product landing page.
